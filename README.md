# pdf-to-tts

财经研究内容到 TTS / 音频节目的 Prompt 工作区。

## 文件命名规则

采用：

```text
排序编号-能力名称.md
```

文件名描述“能力”，不描述版本。版本由文档内部和 Git 历史管理，避免出现 `final`、`new`、`v2-final` 等难以维护的文件名。

编号按 10 递增，便于未来在中间插入新能力：

```text
10-...
20-...
30-...
```

如需插入，可使用 `15-...`、`25-...`，无需整体重命名。

## 当前 Prompt

### `10-report-to-script.md`

**资料 / 研报 → 完整财经 TTS 文案**

用于一份或多份机构研报、行业报告、基金经理交流纪要等材料的分析、Debate Map 和最终节目文案生成。

### `20-xiaojunjun-honghao-editorial.md`

**洪灏原文 + 小君君主持人 → 双人音频节目**

用于保护作者原文，同时在关键节点加入主持人的解释、拆解与连接。

### `30-finance-audio-framing.md`

**已有财经音频 → 开场引导 + 播后分析总结**

用于已经存在音频、SRT 或逐字稿的场景。重点是找到最高信息张力，用开场制造认知缺口，并在原音频结束后完成事实、判断、条件、风险与验证变量的二次整理。

## 职责原则

```text
10：从研究资料生产节目正文
20：把作者原文编辑成双人节目
30：给已经存在的财经音频增加前后包装
```

能力尽量单一，避免多个 Prompt 同时承担同一职责。
