# 参考频道脚本结构研究 V1

> 状态：第一版
> 样本：已收集的多条完整视频脚本，覆盖宏观路演、AI、房地产、地方财政、汇率、税负、公司研报等类型。
> 用途：研究“如何把研报讲细但不讲枯燥”，不复制对方具体话术。

## 1. 核心判断

参考频道真正值得借鉴的，不是“把研报压缩成几个结论”，而是：

> **问题驱动的研报深读。**

研报仍然是内容骨架，问题是叙事主线，主播的解释、比较、计算和判断负责增加价值。

因此应避免两种极端：

```text
极端 A：逐段翻译 / 机械念研报
极端 B：为了节奏，把研报细节压缩成几句结论
```

更理想的是：

```text
先给观众地图
    ↓
进入研报证据
    ↓
在值得停留的数据 / 图表 / 论证处展开
    ↓
解释其经济含义
    ↓
补历史、横向对比、简单计算或其他资料
    ↓
做小结
    ↓
回到研报继续推进
```

## 2. 开场不是越快越好

参考样本常见的开场会完成三件事：

1. 这是什么报告；
2. 为什么现在值得看；
3. 这篇报告最重要的结论是什么。

它并不刻意把所有结论藏到最后，而是常常主动“先说核心结论”。

这样做的逻辑是：

> 观众继续看的理由不是等一个答案，而是想知道这个答案为什么成立。

因此长视频不需要照搬 Shorts 的“十秒必须翻转”逻辑。

## 3. 结论前置，但论证不能省略

参考频道经常先把核心判断告诉观众，然后再说：

> 接下来我们一起过一下这篇研报。

这意味着：

```text
结论前置 ≠ 论证压缩
```

恰恰相反，知道结论以后，后面的任务是让观众经历完整的证据链。

理想状态：

> 观众不是“听主播宣布一个观点”，而是“跟着证据自己走到这个观点”。

## 4. 细节不是负担，而是故事支点

需要保留的不是所有细节，而是具有以下价值的细节：

- 能改变对核心问题的理解；
- 能解释一个反常识结论；
- 能形成明显的数字对比；
- 能揭示结构变化；
- 能验证或削弱机构判断；
- 能让一张图、一组数据产生“原来如此”的效果；
- 能自然引出下一层问题。

因此，一张关键图表可以讲 60 秒甚至更久，只要每一步都在增加解释力。

## 5. 高价值的“停留点”

参考脚本里反复出现的做法：

### 5.1 解释图表，而不是报数字

会解释：

- 横轴 / 纵轴是什么；
- 深浅两条线分别代表什么；
- 什么时候开始分叉；
- 为什么转折；
- 与历史阶段相比哪里不同。

### 5.2 把总量拆成结构

例如：

```text
总量很好
→ 哪些地区贡献？
→ 哪些品类贡献？
→ 是价格还是数量？
→ 谁真正受益？
```

### 5.3 自己做简单二次计算

如果研报给了两个可以组合的数据，允许做透明、可复核的简单计算，并明确：

> 这是基于原始数据的进一步计算，不是机构原文结论。

### 5.4 历史回看

当同一机构 / 专家过去做过类似判断时，可以回看旧预测：

```text
当时怎么判断
→ 后来实际发生了什么
→ 今天的新判断为什么变了
```

这能显著提高内容的研究感。

## 6. 研报与主播价值应交替出现

参考频道有稳定的节奏切换：

```text
研报原始结论
↓
解释 / 类比 / 背景
↓
历史数据或其他资料
↓
主播自己的判断
↓
明确说“继续回到研报”
```

这种切换有两个好处：

- 保留机构作为事实与观点来源；
- 同时建立频道自己的分析价值。

必须严格区分：

```text
研报说什么
主播解释什么
主播额外推导什么
主播不同意什么
```

不能把后二者冒充成机构观点。

## 7. “讲细”不等于“全部讲”

参考频道同样会主动跳过：

- 已经在开头讲过的摘要；
- 观众普遍熟悉、且不影响核心结论的技术细节；
- 与主问题关系弱的附录；
- 重复证明同一件事的低增量信息。

所以删减标准不是“这一段长不长”，而是：

> **这一段是否增加理解。**

## 8. 主播增值的常见方式

在当前样本中，主播的增值主要来自：

- 把机构术语翻译成日常语言；
- 把数字与历史时期比较；
- 横向比较其他机构 / 其他市场 / 其他公司；
- 用现实案例说明抽象机制；
- 自己做透明的小计算；
- 回看旧研报 / 旧预测；
- 找到报告里没有充分讨论的变量；
- 在研报结束后集中给出个人判断。

真正应借鉴的是这些“增值动作”，不是口头禅或句式。

## 9. 一期长视频的推荐节奏

对于单篇深拆，可优先尝试：

```text
A. 开场与报告背景
   - 什么报告
   - 为什么值得讲
   - 核心结论

B. 研报地图
   - 这篇报告分哪几部分
   - 哪一部分是全片重点

C. 深读主体
   - 一个论点 / 图表 / 数据组
   - 解释
   - 横向 / 历史补充
   - 小结
   - 回到研报

D. 研报整体结论回收
   - 这篇报告真正完成了什么论证

E. 主播判断
   - 认同什么
   - 哪些地方存疑
   - 哪些问题仍未回答
   - 后续观察什么数据
```

时长不预设。只要信息增量持续存在，12-20 分钟并不是问题。

## 10. 对当前 S01E01 的直接启示

《China Trade: Strong surplus, uneven growth support》不应该只保留：

> 出口 +25% → 高科技集中 → 就业收入外溢弱。

应让观众真正经历报告的证据链：

```text
贸易总量
→ 地区结构
→ 产品结构
→ 高科技与低端消费品差异
→ 价格与数量
→ 实际产出 / 就业 / 收入
→ 进口结构与 final demand
→ 国内吸收
→ 固投、基建、制造业与财政执行
→ 外部缓冲风险
```

其中应主动识别 2-4 个值得“停下来讲透”的节点，而不是追求每段都快。

## 11. 目前不应模仿的部分

- 不复制对方口头禅；
- 不复制政治化或情绪化表达；
- 不为了人格化强行插入个人生活；
- 不直接搬运对方的标题或封皮措辞；
- 不因为参考频道这么做，就把它当永久正确方法。

参考频道只提供冷启动 Pattern。

最终方法必须由我们自己的 CTR、留存、评论和复看数据校准。
