# Thumbnail / 视频封皮方法

> 状态：实验中
> 说明：当前只是第一版假设。以后每次发布都要把封皮设计与 CTR 一起回流验证。

## 1. 当前观察

参考频道有一种值得测试的封皮逻辑：

> **真实研报截图 + 一句中文强结论 / 强问题**

研报本体负责：

- 权威来源；
- 原始证据感；
- “不是博主凭空说”的可信度。

中文大字负责：

- 核心矛盾；
- 认知缺口；
- 点击理由。

这类封皮不一定视觉最精美，但对研报类财经内容可能更有效。

## 2. 当前建议

### 2.1 保留原始资料感

优先保留：

- 机构名称 / Logo；
- 报告标题的一部分；
- 关键图表 / 高亮原文；
- 明显的 PDF / Research 质感。

不要为了“高级感”把所有原始研报信息都替换成泛财经 AI 图。

### 2.2 中文大字不要承担完整摘要

封皮文案优先表达一个最强命题。

例如：

```text
中国投资人在担心什么？

人民币为什么反而升值？

房价真的见底了？
```

而不是把一整段报告摘要塞在封皮上。

### 2.3 证据画面与点击画面职责分离

PDF 高亮长段落非常适合视频正文 Evidence Shot，未必适合缩略图。

Thumbnail 需要在手机尺寸下仍能一眼读懂。

## 3. 单篇与多篇封皮

### 单篇

可尝试：

```text
一份真实研报首页 / 关键页
+
一句中文核心冲突
```

### 多篇

不要机械堆三四个机构 Logo。

优先：

```text
一个核心问题
+
少量来源证据
```

机构数量只是证据，不应抢走问题本身。

## 4. 第一季需要记录的封皮变量

每集 `60-thumbnail.md` 至少记录：

```yaml
thumbnail_type:
main_text:
source_visible:
  institution:
  report_title_visible:
layout_notes:
text_length:
key_number_used:
final_asset:
```

发布后补：

```yaml
performance:
  impressions:
  ctr:
  traffic_sources:
```

## 5. 待验证问题

- 真实 PDF 首页 vs 图表特写，谁的 CTR 更高？
- 机构 Logo 是否必要？
- 中文大字最适合多少字？
- 红字 / 黄框 / 高亮是否有稳定收益？
- 结论型 vs 问题型封皮哪个更强？
- 标题已经包含机构名时，封皮是否应该减少重复？
- 多篇研报时，应该突出机构冲突还是只突出问题？

在拿到多集真实数据前，这些都保持为 Observation / Hypothesis，而不是 Rule。
