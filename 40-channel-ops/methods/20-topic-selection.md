# 选题根方法

> 状态：第一版

## 1. 选题的基本单位

选题的基本单位不是 PDF 文件，也不是机构，而是：

> **一个值得被观众点击、并且能被原始资料充分回答的问题 / 命题。**

因此正确流程是：

```text
PDF / JSON 库
    ↓
提炼候选命题
    ↓
按问题聚类
    ↓
决定最合适的证据组合
```

而不是：

```text
拿到一份 PDF
    ↓
默认做一期摘要
```

## 2. 候选命题优先寻找什么

优先寻找：

- 与现实利益直接相关的问题；
- 市场正在争论的问题；
- 反常识结论；
- 一个大数字或明确阈值；
- 有时间和幅度的可验证预测；
- 市场共识变化；
- 机构间真实分歧；
- 同一家机构观点变化；
- 有明确原文 / 图表支撑的判断。

## 3. 从 PDF 中提炼命题

不要问：

> 请总结这篇研报。

优先问：

> 这篇研报里有哪些观点能够独立成为一条 YouTube 财经视频的核心问题？

每篇建议先产生 1-5 个候选命题。

例如同一份房地产报告可能产生：

```text
A. 一线房价仍会下跌？
B. 上海为什么可能率先触底？
C. 为什么租金才是真正领先指标？
D. 当前是否适合抄底地产股？
```

四个命题分别评分，不给整篇报告一个笼统分数。

## 4. 先看问题，再看机构

机构品牌是可信度来源，但不能替代命题。

弱：

> 高盛最新中国经济研报解读

更强：

> 利率越来越低，人民币为什么反而升值？

然后再告诉观众：这个判断来自高盛 / 大摩 / 其他机构。

## 5. 先选题，再决定一份还是多份

选题确定后再问：

> 一份报告已经足够回答吗？

如果足够，就单篇深拆。

如果不够，再寻找：

- 能补齐机制的第二份；
- 给出相反结论的第二家机构；
- 能形成时间演变的旧报告；
- 能给出关键数据 / 调研证据的第三份材料。

不要为了“差异化”机械堆报告数量。

## 6. 当前第一版选题发动机

可简化为：

```text
现实利益
  ×
认知冲突
  ×
具体数字 / 预测
  ×
权威原始证据
  ×
当前时效性
```

如果多份材料能增加解释力，再加：

```text
观点分歧 / 共识 / 演变
```

## 7. 频道边界暂不先验固化

第一季不先规定：

- 只能做房地产；
- 只能做宏观；
- 只能做一份 PDF；
- 必须做多机构对比。

先用真实 PDF 库跑选题，再观察高分命题自然聚成哪些主题。

频道边界应由：

```text
资料供给
×
选题质量
×
制作可持续性
×
真实发布表现
```

逐步决定。
