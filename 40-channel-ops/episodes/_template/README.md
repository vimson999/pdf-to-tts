# Episode Template

复制本目录结构创建新一集时，至少先填写下面这些内容。

```yaml
episode_id: S01E01
status: selecting | researching | scripting | producing | published | reviewed
working_topic:
core_question:
format:
  single-report | multi-report-synthesis | multi-report-debate | view-evolution
primary_source:
supporting_sources: []
final_title:
publish_url:
```

## 开集时

先创建：

```text
README.md
10-topic-decision.md
inputs/source-manifest.json
```

不要一开始就填满所有模板文件。

## 研究确认后

按需要增加：

```text
20-research-notes.md
30-claim-evidence-map.md
```

## 文案与包装阶段

增加：

```text
40-script.md
50-title-options.md
60-thumbnail.md
```

## 发布后

增加：

```text
70-publish-metadata.md
80-performance-review.md
```

## 单集结束条件

一集不以“视频上传成功”为结束，而以至少完成一次数据回看为结束。

复盘后标记：

- 本集新增 Observation；
- 是否与过去某个 Observation 形成 Pattern；
- 是否需要修改任何 methods；
- 下一集应该验证什么。
