# S01E01 Report-order Audit

> 日期：2026-09-15
> 对比对象：J.P. Morgan《China Trade: Strong surplus, uneven growth support》 vs `40-script-v5.md`
> 目的：检查 V5 是否因为“围绕核心矛盾重组材料”而压缩或打乱了原研报本身已经成立的论证顺序。

## 1. 原报告实际推进顺序

J.P. Morgan 正文的自然顺序非常清楚：

```text
A. 8 月贸易总量：出口 / 进口 / 顺差
↓
B. 出口去了哪里：EM Asia / US / LatAm / Africa vs EU / Japan / Russia
↓
C. 出口卖什么：高科技、IC、ADP vs 低端消费品
↓
D. 进口结构：AI 基础设施、供应链重建、选择性补库存；不是 broad final demand recovery
↓
E. Technology-led trade resilience：
   技术出口越来越带有价格驱动特征
   → 对 real output / employment / income 的拉动弱于 broad volume growth
   → 长期收益在产业升级与更深科技供应链
↓
F. 外部缓冲风险：能源 / 地缘 / 科技限制 / 欧洲贸易壁垒
↓
G. Policy test：能否把 export resilience 转成 stronger domestic absorption
   → FAI / infrastructure / manufacturing / fiscal execution
   → consumption
```

第 2–6 页随后用图表与表格把上述判断展开：

- export volume vs price；
- export price breakdown；
- China export unit prices；
- high-tech exports；
- exports to US vs RoW；
- trade surplus by partner；
- merchandise export / import breakdown；
- commodity import volume；
- automobile trade；
- China share in global exports。

从第 7 页开始基本进入披露信息，因此真正的研究内容集中在前 6 页。

## 2. V5 的推进顺序

V5 当前大体是：

```text
贸易总量
→ 地区结构
→ 产品结构
→ 价格 vs 数量
→ real output / employment / income
→ 进口结构
→ 国内吸收 / FAI / 财政执行
→ 外部风险
```

与原报告相比有三处明显变化。

### 变化 1：把“价格 vs 数量 / 就业收入”提前到进口之前

原报告先把出口与进口两侧结构都讲完，再进入 `Technology-led trade resilience` 的解释层。

V5 为了尽快回答标题问题，把“为什么就业和收入没有同步放大”提前了。

这不算事实错误，但会让观众更像在听“我们围绕标题组织的一篇文章”，而不是“跟着小摩把这篇报告读下来”。

### 变化 2：把政策考验提前到外部风险之前

原报告的自然递进是：

```text
出口是缓冲
→ 但这个缓冲越来越依赖科技周期
→ 外部缓冲本身也有风险
→ 所以政策考验是把出口韧性转成国内吸收
```

V5 改成：

```text
出口结构
→ 国内吸收 / 政策
→ 最后再补外部风险
```

逻辑仍成立，但削弱了原报告“external cushion becoming less reliable → fiscal urgency”的连续性。

### 变化 3：V5 讲了“价格 vs 数量”，但没有真正带观众读第 2 页图表

V5 主要用概念例子解释：

- 卖 100 台变 120 台 = quantity；
- 单价 / 产品价值提高 = price。

解释是清楚的，但原报告其实已经给了更强的视觉证据：

- `Exports volume vs. price`；
- `Export price breakdown`；
- `China export unit prices`。

尤其是报告把存储芯片 / 模组与“新三样”的价格变化单独拆出来，并显示其与其他产品明显不同。

如果只讲概念、不讲图，等于把研报最像“研报”的部分压缩掉了。

## 3. V5 做对的地方

V5 不需要推翻。

以下部分已经成立：

- 开场与核心矛盾自然；
- 贸易总量 → 地区 → 产品的前半段基本遵循原序；
- 对 `weak domestic absorption`、`real output / employment / income` 的中文解释清楚；
- 能明确区分小摩原文与主播解释；
- 结尾自然，不强行升华；
- 没有机械逐句翻译。

因此 V6 的任务不是重写风格，而是 **恢复原序 + 恢复关键图表的存在感**。

## 4. 是否值得升 V6

结论：**值得。**

原因不是“小修小改”，而是有明确结构性修正：

1. 把进口恢复到价格 / 就业解释之前；
2. 把外部风险恢复到政策考验之前；
3. 新增对第 2 页关键图表的顺序深读；
4. 适度加入第 3 页 `exports to US vs RoW` / high-tech exports 图，帮助观众理解“8 月单月数据”和“这一轮结构变化”不是同一个维度；
5. 保留 V5 已经验证过的自然口语，不增加文案腔。

## 6. 预计效果

V6 不追求单纯变长。

预期变化是：

- 研报原始顺序保留度明显提高；
- “主播在讲自己的文章”的感觉下降；
- “主播在带我读小摩”的感觉上升；
- 图表从视觉素材升级为论证内容；
- 核心问题仍然清楚，但不再为了尽快回答标题而提前拆散报告结构。
