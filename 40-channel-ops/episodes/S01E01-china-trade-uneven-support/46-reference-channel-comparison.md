# S01E01 参考频道脚本对照记录

> 目的：记录为什么当前 V2 脚本需要重构，避免下一轮又重新讨论同一个问题。

## 1. 当前问题

现有 `40-script.md` V2 为了避免“念研报”，压缩得过度。

主要表现：

- 结论推进过快；
- 数据虽然准确，但很多只承担“证明一句话”的作用，没有真正展开；
- 缺少让观众跟着研报完成推理的过程；
- 对图表、结构变化、价格与数量等关键节点停留不足；
- 整体更像“用研报支持一个观点”，而不是“带观众读懂这份研报”。

## 2. 参考频道带来的修正

参考脚本反复说明：

> 长视频不需要把所有内容压到极快。

有效的做法是：

```text
先给结论
→ 再进入研报
→ 关键数据停下来讲
→ 解释为什么
→ 做横向 / 历史补充
→ 小结
→ 回到研报继续
```

细节本身可以成为留存支点，只要它在增加理解，而不是重复信息。

## 3. 对本集的具体重构方向

本集不再采用：

```text
出口 +25%
→ 高科技集中
→ 就业收入外溢弱
→ 内需偏弱
→ 结束
```

改为完整经历以下证据链：

```text
1. 8月贸易总量：出口、进口、顺差到底有多强
2. 地区结构：新兴亚洲、美国、欧洲分别发生了什么
3. 产品结构：高科技、机械电子、低端消费品的分化
4. 关键节点：价格驱动 vs 数量增长
5. 为什么这会影响实际产出、就业和收入的传导
6. 进口 +28.2% 为什么仍不能直接等于 final demand 全面复苏
7. 为什么报告继续讨论固定资产投资、基建、制造业和财政执行
8. 出口作为缓冲垫，如何才能真正转化成国内吸收
9. 外部缓冲为什么越来越依赖科技周期，并面临贸易与地缘风险
10. 最后再给频道自己的判断与后续验证变量
```

## 4. 本集应重点停留的节点

至少考虑以下四处：

### A. 25% 的出口增长到底由谁贡献

不能只报高科技 +56.9%、机械电子 +32.8%、低端消费品 +8.5%。

要解释：

- 为什么三个增速差距重要；
- 它说明出口结构发生了什么变化；
- 为什么“总出口 +25%”会掩盖内部高度不均衡。

### B. 价格与数量

这是全片最关键的解释节点之一。

要把“出口金额增长”与“实际产出增长”区分开，并解释为什么价格驱动的科技出口不必然带来同等规模的生产、用工和收入扩张。

### C. 进口 +28.2%

需要解释高科技进口、AI 基础设施、供应链重建、补库存和 final demand 之间的区别。

### D. 国内吸收

要解释为什么一篇贸易报告最后会谈：

- 固定资产投资；
- 基建投资；
- 制造业投资；
- 政府债发行进度；
- 消费。

这里其实是整篇报告从“贸易数据”进入“宏观传导”的桥。

## 5. 当前状态

`40-script.md` V2 暂时保留，作为一次有价值的失败样本，不直接删除。

下一版目标不是简单“加长”，而是：

> **增加证据旅程、解释深度和关键停留点，同时保持问题主线清晰。**

下一步：按 `methods/15-reference-script-structure.md` 与更新后的 `methods/70-video-structure.md`，重构 S01E01 V3。
