## 当前原则

- 先按 `single-report` 设计完整一期；
- 不为了“多研报”强行加入其他报告；
- 只有其他 PDF 能补上主报告没有解释清楚的关键机制、反例或风险时才加入；
- “普通人没感觉”可以作为传播语言候选，但正文必须严格区分：报告明确支持的是就业、收入、实际产出与国内吸收的传导偏弱，而不是一个可直接量化的主观“体感指数”；
- 当前采用“问题驱动的研报深读”：研报是骨架，问题是主线，解释和比较负责增值；
- 通篇坚持：自然优先、信息优先、技巧克制；重要处才强调，不强求每一段都有转折或总结；
- 开头可以轻设计，结尾优先自然收住，不强求金句、三点总结或价值升华。
