把 2026-09-15 提供的 PDF 列表作为一个可复盘的候选池快照，后续所有选题筛选、聚类、评分和单集决策都尽量能够追溯回本批次。

## Public Repo 清洗规则

原始导出包含 `fileId`、`topicId` 等资源标识。由于本仓库为公开仓库，不把这些字段写入 Git。

Git 中的 `source-list.json` 是用于复盘的**安全化、规范化快照**，只保留选题决策需要的字段：

- 报告名；
- 机构；
- 报告日期（能从文件名可靠解析时）；
- 上传时间；
- 下载次数；
- 下载状态；
- 文件大小；
- 重复项数量。

原始 JSON 用 SHA-256 指纹标识，便于确认未来拿到的源文件是否与本次输入完全一致。

## 规范化

第一轮仅处理较确定的重复形式：

- 完全相同文件名；
- `_带图片_加密_1` 这类同报告副本后缀；
- 文件名末尾 `(1)` 副本标记。

结果：

```yaml
raw_items: 1347
normalized_items: 1334
collapsed_duplicate_rows: 13
```

语义近似但标题不同的报告暂不自动合并，避免误删真正不同版本；后续在主题聚类阶段处理。

## 本批次留痕链

```text
source-list.json
  ↓
元数据初筛 / 主题聚类

selection-result.md
```
