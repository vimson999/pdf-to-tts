# S01-B01 元数据初筛结果

> 状态：Phase 0 / Metadata-only
>
> 本文件只根据 JSON 中的报告名、日期、下载状态、下载次数等元数据做第一轮筛选。**没有读取 PDF 正文的候选，不做最终事实判断，也不直接进入成片。**

## 1. 本轮先验证什么

第一季不先把频道边界写死，而是验证：

1. 哪类“问题”能从现有研报库中稳定找到高质量证据；
2. 单篇深拆、多人合流、多人碰撞、观点演变四种内容形态分别适合什么题；
3. 上游 `downloadCount` 是否能作为一个弱兴趣信号；
4. 根方法的评分是否能预测后续 CTR、留存与观看量。

## 3. 当前元数据级优先顺序

在没有读取正文之前，暂定深读顺序：

```text
1. 中国消费是否复苏
2. 上游再通胀为何传导偏弱
3. AI到底冲击谁 / 富裕消费者为何更安全
4. 厄尔尼诺如何进入生活成本
5. 中国出口强、增长支撑却不均衡
6. 外资为什么重新做多人民币
7. AI巨额资本开支到底值不值
8. 后预售时代谁受益
9. 老龄化亚洲
10. 高盛本地路演（基准样本）
```

这不是最终 Top 10，只是**决定下一步先读哪些 PDF**的顺序。
