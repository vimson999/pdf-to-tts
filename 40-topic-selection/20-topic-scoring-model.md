# 研报视频选题评分模型

> 状态：第一版
> 目标：从大量 PDF 中筛出最值得做成财经视频的候选题，而不是给研报本身做学术质量评分。

## 1. 评分对象

评分对象不是“整篇 PDF”，而是从 PDF 中提炼出来的**候选命题**。

一份研报可以产生多个候选命题，每个命题单独打分。

例如一篇《中国经济展望》可能产生：

- 消费复苏为何困难；
- 人民币为什么可能继续升值；
- 房地产何时触底；
- AI 如何影响就业；
- 财政政策为何低于市场预期。

## 2. 十个正向维度

每项建议按 1-5 分评分。

### 2.1 时效性 `timeliness`

核心问题：

> 为什么观众现在要看？

高分特征：

- 刚发布；
- 正处于市场讨论期；
- 与近期政策、财报、价格波动、重大事件直接相关；
- 结论尚未被市场充分消化。

### 2.2 大众相关性 `broad_relevance`

核心问题：

> 这个议题是不是只有专业人士关心？

高分主题通常包括：

- 房地产；
- 就业；
- 收入；
- 消费；
- 税收；
- 汇率；
- 股市；
- 黄金；
- AI 对现实生活的影响。

### 2.3 个人利益映射 `personal_impact`

核心问题：

> 观众能否马上理解“这和我有什么关系”？

优先寻找：

```text
我的钱
我的工作
我的房子
我的收入
我的资产
我的生活成本
```

### 2.4 反常识度 `counter_intuition`

核心问题：

> 有没有明显的认知冲突？

高分结构：

```text
A 明明如此，为什么 B 却相反？
```

例如：

- 低利率但强汇率；
- GDP 尚可但居民体感弱；
- AI 提升效率但就业和消费承压；
- 行业销量增长但利润恶化。

### 2.5 结论锋利度 `thesis_sharpness`

核心问题：

> 能不能压缩成一句让人立刻明白的判断？

弱：

> 对中国消费趋势的若干观察。

强：

> 不必期待短期消费复苏。

### 2.6 数字冲击力 `numeric_punch`

核心问题：

> 有没有一个数字能成为认知锚点？

优先：

- 大比例变化；
- 大人数；
- 目标价 / 潜在涨跌幅；
- 明确的价格区间；
- 极值；
- 历史新高 / 新低。

### 2.7 预测具体度 `forecast_specificity`

核心问题：

> 结论是否可以在未来被验证？

强预测通常具备：

```text
对象 + 时间 + 幅度 + 条件
```

例如：

> 2027 年上海房价上涨 6%-12%。

通常比：

> 长期看好房地产。

更适合视频选题。

### 2.8 权威性 `source_authority`

核心问题：

> 谁说的，为什么值得听？

来源可以包括：

- 高盛；
- 摩根士丹利；
- 摩根大通；
- 瑞银；
- 伯恩斯坦；
- 野村；
- 花旗；
- 巴克莱；
- 行业专家 / 官方机构 / 高质量调研。

注意：权威性是信任放大器，不应单独决定选题。

### 2.9 证据可视化 `evidence_visuality`

核心问题：

> PDF 中有没有可以直接给观众看的证据？

包括：

- 关键原文；
- 图表；
- 调查结果；
- 目标价；
- 数据表；
- 情景分析；
- 结论框。

这直接影响后续视频的“Evidence Shot”质量。

### 2.10 多研报碰撞价值 `cross_report_conflict`

核心问题：

> 同一个问题，我们是不是还有第二、第三家机构给出不同答案？

高分情况：

- 明确方向分歧；
- 目标价明显不同；
- 共同结论但逻辑不同；
- 同一数据被不同机构解释成相反含义。

注意：多机构本身不是选题，必须围绕同一个核心问题组织。

## 3. 惩罚项

### 3.1 同质化 / 题材疲劳 `topic_fatigue`

建议 0 到 -5 分。

判断：

- 最近是否连续做过相同题材；
- 只是重复“房价见底 / 未见底”；
- 新报告有没有实质新增信息；
- 用户是否已经形成审美疲劳。

### 3.2 过度技术化 `technical_distance`

建议 0 到 -3 分。

如果选题需要大量背景知识才能理解，且难以映射到现实利益，应扣分。

### 3.3 结论依赖大量前提 `fragile_thesis`

建议 0 到 -3 分。

如果一句强标题必须省略太多关键限定条件才成立，应扣分，避免为了点击制造误导。

## 4. 推荐总分

第一版可先使用等权重：

```text
base_score = 10 个正向维度之和
final_score = base_score - topic_fatigue - technical_distance - fragile_thesis
```

满分约 50 分。

初始分层：

```text
A+ : 42-50   优先立即做
A  : 36-41   强候选
B  : 29-35   可做，需优化角度或与其他研报组合
C  : 22-28   信息有价值，但视频传播性偏弱
D  : <22     暂不进入生产队列
```

这些阈值只是第一版，后续必须用真实发布数据校正。

## 5. 推荐输出格式

每个候选命题至少输出：

```yaml
report:
  institution:
  date:
  file:

candidate_topic:
  thesis:
  audience_question:
  conflict:
  key_number:
  forecast:

scores:
  timeliness:
  broad_relevance:
  personal_impact:
  counter_intuition:
  thesis_sharpness:
  numeric_punch:
  forecast_specificity:
  source_authority:
  evidence_visuality:
  cross_report_conflict:

penalties:
  topic_fatigue:
  technical_distance:
  fragile_thesis:

final_score:
priority:

recommended_format:
  single_report | multi_report

possible_title_angles:
  -
  -
  -
```

## 6. 重要原则

### 不给“研报质量”打分

一篇非常优秀的专业研报，也可能不是好视频。

### 不给“机构品牌”过高权重

高盛并不能自动把冷门技术议题变成爆款。

### 先提炼命题，再评分

错误：

```text
给这 100 份 PDF 文件名直接打分
```

更好：

```text
PDF -> 候选命题 -> 每个命题打分
```

### 强标题不能脱离证据

所有强结论必须能够回到 PDF 原文、图表或明确推导链条中验证。
