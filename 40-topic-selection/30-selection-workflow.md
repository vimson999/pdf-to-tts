# PDF 库选题工作流

> 状态：第一版
> 目标：把大量 PDF / 研报库存，稳定转换成**新宏观 / 经济现实类频道**可执行的 Top 5 视频选题。
>
> 本流程不用于「兼听研报」的具体标的选题。兼听研报应另建一套以公司、估值、目标价、盈利变化、催化剂与风险分歧为中心的选题流程。

## 1. 输入

最低要求：

```text
文件名
机构
日期
主题（如果文件名已包含，可不单独提供）
```

更理想的输入：

```text
PDF 本体
摘要
目录
关键图表
已有标签
```

如果 PDF 数量很多，可以先用文件名和元数据做初筛，再只读取高潜候选的全文。

## 2. 第一步：建立报告清单

将研报标准化成：

```yaml
institution:
date:
report_title:
file:
asset_or_topic:
report_type:
  macro | strategy | expert_call | survey | policy | sector
```

此阶段不要急着写标题。

## 3. 第二步：从每份报告中提炼“命题”

对每份 PDF 不问：

> 请总结这篇研报。

而问：

> 这篇研报里有哪些观点，能够独立成为一个面向大众的 YouTube 财经视频选题？

每篇建议先产生 1-5 个候选命题。

候选命题重点寻找：

- 普通人现实利益；
- 市场争议；
- 反常识结论；
- 大数字；
- 明确预测；
- 政策或市场共识变化；
- 能被原始 PDF 明确验证的结论。

## 4. 第三步：给候选命题打分

使用 `20-topic-scoring-model.md`。

不是给 PDF 打一个总分，而是给每个候选命题分别评分。

例如：

```text
同一份房地产宏观报告

命题 A：一线房价仍会下跌
命题 B：上海可能率先触底
命题 C：租金才是真正领先指标
命题 D：政策效果正在边际减弱
```

四个命题应该分别评分。

## 5. 第四步：寻找“碰撞关系”

对高分命题扫描其他报告：

> 有没有其他机构讨论同一个现实问题？

然后分类：

### 共识型

```text
高盛、大摩、小摩都认为 X
```

价值在于：

> 市场可能低估了机构共识。

### 分歧型

```text
高盛看多
大摩谨慎
瑞银给出第三种路径
```

价值在于：

> 同一个事实为什么会被解释成不同结论？

### 时间演变型

```text
同一家机构 3 个月前：A
现在：B
```

价值在于：

> 什么变量发生了变化？

对本频道而言，多家机构只用于增强问题解释，不应为了“凑多家投行”而合并。

## 6. 第五步：决定单篇还是多篇

### 适合单篇

满足以下条件之一：

- 单一研报已有非常强的独家结论；
- 有一个非常清晰的大数字；
- 有专家访谈 / 调研等独特证据；
- 其他机构没有足够可比材料。

### 适合多篇

满足：

- 围绕同一个明确现实问题；
- 机构观点有真实分歧或高价值共识；
- 合并后能增强解释，而不是单纯增加信息量。

错误多篇结构：

> 七家投行 2027 年展望大汇总

更好的结构：

> 2027 年人民币会继续升值吗？三家投行为什么给出不同答案

## 7. 第六步：生成“观众问题”而不是论文标题

每个 A / A+ 候选都要生成一个 `audience_question`。

例如：

研报语言：

> Residential property price stabilization remains conditional on rental yield improvement.

视频问题：

> 房价真正见底，为什么要先看租金？

研报语言：

> RMB appreciation can coexist with structurally low rates.

视频问题：

> 利率这么低，人民币为什么反而升值？

## 8. 第七步：标题角度测试

每个候选至少产生三种角度：

### 结论型

> 高盛：短期不必期待消费复苏

### 冲突型

> 利率越来越低，人民币为什么反而升值？

### 数字 / 预测型

> 2027 上海房价或上涨 6%-12%，依据是什么？

先决定命题，再决定标题，不允许用标题包装掩盖弱选题。

## 9. 第八步：Top 5 输出

最终建议只保留 5 个进入人工决策。

推荐表：

| Rank | 核心命题 | 机构 | 总分 | 单篇/多篇 | 最强钩子 | 主要风险 |
|---|---|---|---:|---|---|---|
| 1 |  |  |  |  |  |  |
| 2 |  |  |  |  |  |  |
| 3 |  |  |  |  |  |  |
| 4 |  |  |  |  |  |  |
| 5 |  |  |  |  |  |  |

同时明确：

- 为什么排第一；
- 对应哪种成功题型；
- PDF 中哪些页 / 原文 / 图表可以作为证据；
- Thumbnail 最可能抓哪句话；
- 是否有误导风险或关键限定条件。

## 10. 第九步：进入下游生产

选中 Top 1 后：

```text
选题确定
  ↓
读取完整 PDF / 相关多份 PDF
  ↓
建立 Claim / Evidence Map
  ↓
10-report-to-script.md
  ↓
TTS
  ↓
30-finance-audio-framing.md（如需要已有音频前后包装）
  ↓
SRT / 视觉导演
  ↓
Thumbnail
  ↓
发布
```

## 11. 第十步：发布后回流数据

选题系统必须有反馈闭环。

每期发布后记录：

```yaml
topic:
title:
thumbnail_thesis:
institution:
format:
  single_report | multi_report

performance:
  impressions:
  ctr:
  views_24h:
  views_7d:
  avg_view_duration:
  avg_percentage_viewed:
  first_30s_retention:
  traffic_sources:
```

随后判断：

- 是选题强，还是标题强；
- 是 CTR 高但留存差；
- 是选题专业但推荐流量弱；
- 哪个评分维度被高估 / 低估。

最终目标不是永久模仿参考频道，而是逐渐用新频道自己的真实数据训练出：

> **独立的宏观研报视频选题模型。**
