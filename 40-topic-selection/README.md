# 40-topic-selection

财经研报视频的**选题研究与筛选工作区**。

这个目录解决的是整条 `PDF -> TTS -> Video` 链路最上游的问题：

> **手里有很多 PDF 时，先做哪一篇，为什么做，应该从什么角度做。**

这里不负责写最终口播稿，也不负责视觉执行，而是负责把“研报库存”变成“值得做的视频选题”。

## 为什么单独使用文件夹

选题不是一个固定 Prompt，而是一个会持续演化的专题能力，后续会逐步增加：

- 参考频道样本研究；
- 选题评分模型；
- PDF 库扫描规则；
- 单篇研报的命题提炼；
- 多家研报的观点碰撞；
- 标题 / 封皮角度；
- 实际发布后的 CTR、观看量、留存反馈；
- 反向修正评分权重。

因此这里采用目录，而不是继续堆叠单个根目录 Markdown。

## 当前文件

### `10-reference-channel-patterns.md`

记录当前参考频道的历史样本观察，以及从数据中提炼出的稳定选题规律。

### `20-topic-scoring-model.md`

记录第一版研报视频选题评分模型，包括正向指标、惩罚项和推荐分层。

### `30-selection-workflow.md`

记录从 PDF List 到 Top 5 候选题的标准流程，供后续人工或 Skill 自动化执行。

## 核心原则

选题不是“哪份研报信息最多”，而是寻找：

```text
大众问题 × 强矛盾 × 权威证据 × 可验证结论
```

对于“兼听研报”类内容，再增加：

```text
同一核心问题 × 多机构分歧/共识
```

多家机构不是选题本身，而是用来增强证据结构和观点碰撞。

## 与其他文件的职责关系

```text
40-topic-selection/
    先决定“做什么、从什么角度做”

10-report-to-script.md
    再把选中的研报做成完整财经 TTS 文案

30-finance-audio-framing.md
    对已有音频增加开场钩子和结尾分析
```

后续如果选题能力稳定，可以再从这里抽出独立 Skill，例如：

```text
research-topic-selector
```

目标输入：PDF 文件列表 / 研报元数据 / PDF 本体。

目标输出：候选命题、评分、排序、推荐组合方式和标题角度。
