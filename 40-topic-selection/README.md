# 40-topic-selection

财经研报视频的**选题研究与筛选工作区**。

> 当前专题服务对象：**一个独立的新宏观 / 经济现实类 YouTube 频道（频道名待定）**。
>
> **不属于「兼听研报」频道。**「兼听研报」继续聚焦具体公司 / 具体标的，多家投行围绕同一标的的观点、估值、催化剂与风险比较。两类频道的受众意图和选题机制不同，不混用。

这个目录解决的是新宏观频道整条 `PDF -> TTS -> Video` 链路最上游的问题：

> **手里有很多 PDF 时，先做哪一个现实问题，为什么做，应该从什么角度做。**

这里不负责写最终口播稿，也不负责视觉执行，而是负责把“研报库存”变成“值得做的视频选题”。

## 两个频道的边界

### 新宏观研报频道（本目录）

核心入口是**问题 / 现实影响**：

```text
房价 / 就业 / 收入 / 消费 / 税收 / 汇率 / 政策 / AI 对普通人的影响
        ↓
从研报中寻找强命题与原始证据
        ↓
解释“这件事为什么和普通人有关”
```

典型选题：

- 一线城市房价还会不会跌？
- AI 会不会替代某类工作？
- 低利率环境下人民币为什么反而升值？
- 财政压力最终可能由谁承担？

### 兼听研报（不属于本目录）

核心入口是**具体标的**：

```text
公司 / 股票 / 行业龙头
        ↓
高盛 / 大摩 / 小摩 / 伯恩斯坦等多机构观点
        ↓
业绩、估值、目标价、催化剂、风险、分歧
```

典型选题：

- 小米：三家投行对汽车盈利拐点为何判断不同？
- 智谱 AI：ARR 高增长之下，三家机构为何给出不同目标价？

因此不能因为两边都使用“研报”，就把它们当成一个频道或一套完全相同的选题逻辑。

## 为什么单独使用文件夹

选题不是一个固定 Prompt，而是一个会持续演化的专题能力，后续会逐步增加：

- 参考频道样本研究；
- 选题评分模型；
- PDF 库扫描规则；
- 单篇研报的命题提炼；
- 多家研报的观点碰撞；
- 标题 / 封皮角度；
- 实际发布后的 CTR、观看量、留存反馈；
- 反向修正评分权重。

因此这里采用目录，而不是继续堆叠单个根目录 Markdown。

## 当前文件

### `10-reference-channel-patterns.md`

记录当前参考频道的历史样本观察，以及从数据中提炼出的稳定选题规律。

### `20-topic-scoring-model.md`

记录第一版宏观研报视频选题评分模型，包括正向指标、惩罚项和推荐分层。

### `30-selection-workflow.md`

记录从 PDF List 到 Top 5 候选题的标准流程，供后续人工或 Skill 自动化执行。

## 核心原则

本频道选题不是“哪份研报信息最多”，而是寻找：

```text
现实利益 × 强矛盾 × 权威证据 × 可验证结论
```

多家机构只有在围绕**同一个现实问题**形成真正的共识、分歧或观点演变时才有价值。

> **多家机构是证据结构，不是选题本身。**

## 与其他文件的职责关系

```text
40-topic-selection/
    先决定新宏观频道“做什么、从什么角度做”

10-report-to-script.md
    再把选中的研报做成完整财经 TTS 文案

30-finance-audio-framing.md
    对已有音频增加开场钩子和结尾分析
```

后续如果这套选题能力稳定，可以再从这里抽出独立 Skill，例如：

```text
macro-research-topic-selector
```

目标输入：PDF 文件列表 / 研报元数据 / PDF 本体。

目标输出：候选命题、评分、排序、推荐组合方式和标题角度。
